# UAE Drive, Shanghai Drive and Pakistan Drive

Browser-based 3D driving simulators built by Raed Alvi in JavaScript and Three.js (WebGL) from OpenStreetMap data: Dubai and Abu Dhabi, and Shanghai (Qiantan to Lujiazui), with simulated traffic, traffic signals, turn-by-turn navigation and on-screen controls for phones.

Play: https://raedalvi.github.io/uae-drive-play/

Map data © OpenStreetMap contributors (ODbL). Building footprints: Overture Maps Foundation (ODbL 1.0), including Google Open Buildings (CC BY 4.0) and Microsoft Global ML Building Footprints (CDLA Permissive 2.0). Elevation: Terrain Tiles on AWS (Mapzen, including SRTM and other public sources). Map tiles: OpenFreeMap. Routing: Valhalla (FOSSGIS public server). 3D engine: Three.js. Map engine: MapLibre GL.
